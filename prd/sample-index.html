Tentang Proyek

Yayasan Elmasudy membutuhkan website untuk memperkenalkan lembaga, program-program pembelajaran Al-Qur'an, serta galeri kegiatan santri kepada masyarakat luas. Website ini dibangun agar calon santri dan orang tua dapat dengan mudah memahami program yang tersedia dan menghubungi pihak yayasan secara langsung.

Fitur Utama

  • Hero section dengan CTA "Hubungi Kami"
  • Section keunggulan lembaga (Tenaga Pengajar, Pendidikan, Standar Internasional)
  • Listing Program Daurah Ramadhan (DTN, MTN, STOR)
  • Listing Program Sekolah (MQL, MATAYA, STO, ElMasudy Privat)
  • Section About Us / sejarah lembaga
  • Section Visi & Misi
  • Galeri foto kegiatan santri (grid gallery)
  • Logo mitra/partner lembaga
  • Footer dengan info kontak & sosial media
  • Desain responsif untuk mobile

Tech Stack

Next.js React Tailwind CSS Vercel

Tantangan & Solusi

Tantangan

Menyusun banyak program dan kategori (Daurah & Sekolah) agar tetap mudah dipahami pengunjung, serta mengelola galeri foto kegiatan dalam jumlah besar tanpa memperlambat loading halaman.

Solusi

Membagi program ke dalam grid card yang jelas per kategori, serta melakukan optimasi gambar dan lazy loading pada bagian galeri untuk menjaga performa halaman tetap cepat.
